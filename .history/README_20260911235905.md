# TradeZella Clone

A trading journal and analytics dashboard inspired by modern trading platforms.

The goal of this project is to build a full-stack trading journal where traders can record trades, analyze performance, track accounts, and review their trading behavior.

## 🚀 Features

* Trading dashboard
* Trading accounts
* Trade journal
* Performance analytics
* Win/loss statistics
* Risk/reward analysis
* Trade history
* Strategy tracking
* Responsive UI
* Authentication
* Database integration

## 🛠️ Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS
* PostgreSQL
* Prisma
* Docker
* GitHub Actions

## 🧑‍💻 Development

Clone the repository:

```bash
git clone <your-repository-url>
cd tradezella-clone
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
